# Дизайн: запуск HomeBot без консоли, с иконкой в трее

Дата: 24.11.2026. Статус: согласовано пользователем. Размер: маленькое изменение.

## Намерение

Ярлык `HomeBot` на рабочем столе должен запускать посредника между агентом и Telegram без
появления чёрного окна консоли. При этом процесс должен оставаться видимым и управляемым
через иконку в системном трее: пользователь видит, что бот работает, и может корректно его
остановить.

## Подходы

1. **`pythonw.exe` + иконка в трее на `ctypes` (выбран).** Консоль не создаётся; трей
   реализован через Win32 `Shell_NotifyIcon` и скрытое окно для сообщений. Бот работает
   в daemon-потоке, главный поток крутит обработчик сообщений трея. Стандартная библиотека.
2. **Только `pythonw.exe`.** Консоли нет, но остановка — только через диспетчер задач.
3. **Свёрнутое окно консоли.** Окно остаётся на панели задач, цель не достигается.

## Решение

- Новый модуль `homebot/tray.py`:
  - `run_tray(config: Config | None = None) -> int` — загружает конфиг (по умолчанию из `.env`
    проекта), создаёт `Runtime` через `build_runtime`, запускает `serve_forever` в daemon-потоке,
    регистрирует иконку в трее и запускает цикл сообщений.
  - Иконка: простой значок через `LoadIcon(0, IDI_APPLICATION)`; подсказка «HomeBot».
  - Меню: «Статус» (показывает `send_enabled` и число ожидающих запросов через `MessageBox`)
    и «Выход» (вызывает `runtime.shutdown()`, удаляет иконку, выходит).
  - Ошибки запуска показываются `MessageBox`, а не пишутся в невидимую консоль.
- Ярлык `C:\Users\veles\Desktop\HomeBot.lnk` меняет цель на
  `E:\Install\Python\Python313\pythonw.exe -m homebot.tray`, рабочая папка `E:\Projects\HomeBot`.
- `start.bat` остаётся как резервный способ запуска с консолью (для диагностики).
- Защита от второго экземпляра сохраняется: проверка port 8765 в `start.bat`; в tray-режиме
  ошибка привязки порта показывается сообщением.

## Ограничения и не-цели

- Только Windows, только стандартная библиотека Python 3.13.
- Не ставится автозапуск Windows и служба — только ярлык.
- Не меняются режимы `SEND_ENABLED`, токены и логика бота.

## Проверка

- Юнит-тесты `unittest` с подменой Win32-вызовов: регистрация/удаление иконки, обработка
  пунктов меню, вызов `shutdown` при выходе, отсутствие обращения к сети в тестах.
- Вручную: запуск через ярлык — нет окна консоли, иконка в трее, `/health` отвечает,
  «Статус» показывает состояние, «Выход» останавливает процесс, повторный запуск работает.
